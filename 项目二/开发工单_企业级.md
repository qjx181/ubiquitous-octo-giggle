## 一、项目概述

### 1.1 项目背景

基于大语言模型（LLM），开发一个针对《招股说明书1.pdf》的企业级智能问答系统，能够高效检索文档内容并生成准确、简洁、可溯源的回答。系统需满足企业环境的稳定性、安全性、可维护性和可扩展性要求。

### 1.2 核心能力

| 能力 | 说明 | 企业级要求 |
|------|------|-----------|
| Query理解 | 意图识别、消歧、复杂问题分解、关键词抽象 | 支持多轮对话上下文，意图识别准确率≥90% |
| 检索与生成 | PDF解析 → 分块 → 向量化 → 语义检索 → LLM答案生成 | 检索召回率≥85%，响应时间≤3s |
| 用户体验 | 简洁的交互界面，支持输入、展示和反馈 | 支持并发访问，界面响应≤100ms |
| 系统监控 | 全链路日志、性能指标、异常告警 | 可观测性覆盖100%核心链路 |
| 数据安全 | 敏感信息保护、访问控制、审计日志 | 符合企业数据安全规范 |

### 1.3 技术栈（企业级）

| 组件 | 生产环境方案 | 开发/测试环境方案 | 选型理由 |
|------|------------|----------------|---------|
| 后端框架 | FastAPI + Uvicorn | FastAPI + Uvicorn | 高性能异步框架，自动API文档 |
| 向量数据库 | **Milvus**（集群版） | **Milvus** Standalone | 高性能分布式向量数据库，支持十亿级向量检索 |
| Embedding模型 | BGE-M3 | BGE-M3 | 多语言支持，1024维高性能 |
| LLM | **SGLang**（本地部署） | **SGLang** | 高性能LLM推理引擎，支持多GPU并行、投机解码、前缀缓存 |
| PDF解析 | PyMuPDF (fitz) | PyMuPDF | 成熟稳定，支持复杂PDF结构 |
| 前端 | React + TypeScript + Ant Design | React + TypeScript | 企业级UI组件库，类型安全 |
| 缓存 | Redis | 本地字典 | 高频Query缓存，会话管理 |
| 监控 | Prometheus + Grafana | 日志文件 | 企业标准监控栈 |
| 日志 | 结构化JSON日志 + ELK | 结构化JSON日志 | 便于聚合分析和告警 |
| 配置管理 | Pydantic Settings + 环境变量 | Pydantic Settings | 类型安全，支持多环境 |
| 测试 | pytest + coverage + CI/CD | pytest + coverage | 自动化测试保障质量 |

## 三、功能需求详述（企业级）

### 3.1 Query理解模块（增强版）

#### 3.1.1 意图识别

- **输入**：用户原始问题
- **处理**：
  1. 基于规则快速匹配（问候、空输入等）
  2. LLM深度分类（支持细粒度意图）
  3. 多轮对话上下文继承
- **输出**：意图标签 + 置信度分数

| 意图标签 | 说明 | 示例 | 处理方式 |
|---------|------|------|---------|
| financial | 财务数据类 | "营业收入是多少？" | RAG检索+数值提取 |
| risk | 风险因素类 | "公司有什么经营风险？" | RAG检索+分类汇总 |
| business | 业务介绍类 | "公司主要做什么业务？" | RAG检索+概括 |
| legal | 法律合规类 | "有没有未决诉讼？" | RAG检索+法律条款关联 |
| management | 管理层信息类 | "董事长是谁？" | RAG检索+实体提取 |
| comparison | 对比分析类 | "近三年营收对比" | 问题分解+多轮检索 |
| greeting | 问候/闲聊 | "你好" | 直接回复，不走RAG |
| unclear | 意图不明确 | 模糊提问 | 追问澄清 |
| out_of_scope | 超出范围 | "今天天气如何？" | 礼貌拒绝+范围说明 |

#### 3.1.2 消歧与上下文管理

- **会话状态管理**：Redis存储多轮对话上下文
- **消歧策略**：
  - 指代消解："该公司的营收" → 解析指代对象
  - 时间补全："去年" → 结合当前时间解析为具体年份
  - 实体链接："这家公司" → 链接到具体公司实体
- **追问模板**：标准化追问话术，保持专业礼貌

#### 3.1.3 问题分解与执行计划

- **复杂问题拆解**：
  - 多条件问题："A公司2021-2023年营收和净利润" → 6个子问题
  - 对比问题："A公司和B公司营收对比" → 分别检索+对比分析
  - 因果问题："营收下降的原因" → 检索事实+分析推理
- **执行计划生成**：确定子问题执行顺序、依赖关系

### 3.2 检索与生成模块（企业级）

#### 3.2.1 混合检索策略

| 检索方式 | 权重 | 适用场景 | 实现方案 |
|---------|------|---------|---------|
| 向量检索（语义） | 70% | 理解用户意图，召回语义相关 | Milvus IVF_FLAT + 内积距离 |
| BM25关键词检索 | 20% | 精确匹配专业术语、数字 | 自建倒排索引或Elasticsearch |
| 结构化过滤 | 10% | 按章节、页码、时间范围过滤 | Milvus标量字段过滤 |

- **重排序（Reranker）**：Cross-Encoder精排，提升top-k准确率
- **结果融合**：RRF（Reciprocal Rank Fusion）算法融合多路召回

#### 3.2.2 缓存策略

| 缓存层级 | 存储 | 过期策略 | 用途 |
|---------|------|---------|------|
| L1 - 应用缓存 | 内存字典 | 5分钟TTL | 高频Query结果 |
| L2 - Redis缓存 | Redis | 1小时TTL | 会话状态、Query结果 |
| L3 - 向量缓存 | Milvus | 持久化 | 已计算向量 |

#### 3.2.3 答案生成（增强版）

- **Prompt工程**：
  - 系统Prompt：角色定义、回答规范、安全约束
  - 上下文Prompt：检索到的chunks + 引用标记
  - 用户Prompt：原始问题 + 对话历史
- **生成后处理**：
  - 引用校验：验证每个引用是否在检索内容中
  - 敏感词过滤：企业级敏感信息检测
  - 格式标准化：统一输出格式（Markdown表格、列表等）

### 3.3 用户体验模块（企业级）

#### 3.3.1 前端界面（React + TypeScript）

- **页面布局**：
  - 顶部：企业Logo + 系统标题 + 用户中心
  - 左侧：对话历史列表（支持搜索、归档）
  - 中间：对话区域（消息气泡、引用高亮、来源标注）
  - 右侧：知识面板（相关文档、推荐问题）
  - 底部：输入框（支持多行、快捷问题、文件上传）
- **功能特性**：
  - 多轮对话上下文保持
  - 回答中引用可点击跳转原文
  - 支持Markdown渲染（表格、公式、代码块）
  - 夜间模式切换
  - 响应式布局（支持移动端）

#### 3.3.2 反馈与优化闭环

- **即时反馈**：👍/👎 + 文字反馈
- **反馈数据**：
  - 记录Query、回答、引用来源、用户反馈
  - 定期生成质量报告（周/月）
  - 识别低质量回答模式，针对性优化
- **A/B测试**：支持多版本Prompt/模型对比

### 4.2 安全要求

| 安全维度 | 要求 | 实现方案 |
|---------|------|---------|
| 认证授权 | JWT Token + RBAC权限控制 | FastAPI依赖注入 |
| 输入安全 | SQL注入/XSS/CSRF防护 | 参数校验、输出转义 |
| 数据安全 | 敏感信息脱敏、传输加密 | HTTPS、字段级加密 |
| 审计日志 | 全链路操作记录 | 结构化日志 + 审计表 |
| 访问控制 | API限流、IP白名单 | Nginx + FastAPI中间件 |

### 4.3 可维护性要求

| 维度 | 要求 | 实现方案 |
|------|------|---------|
| 代码质量 | 类型覆盖率100%、单元测试覆盖率≥80% | mypy、pytest、coverage |
| 文档 | API文档自动生成、架构文档、部署文档 | FastAPI自动文档、Markdown |
| 配置管理 | 环境分离、敏感配置加密 | Pydantic Settings、Vault |
| 日志 | 结构化JSON、全链路Trace ID | logging + middleware |
| 监控 |  metrics、logs、traces三支柱 | Prometheus + Grafana + Jaeger |

### 7.2 全链路日志设计

```python
# middleware/logging.py — 结构化日志中间件
import time
import uuid
from fastapi import Request
from starlette.middleware.base import BaseHTTPMiddleware

class LoggingMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        request_id = str(uuid.uuid4())
        request.state.request_id = request_id
        
        start_time = time.time()
        
        # 记录请求日志
        logger.info(
            "request_started",
            extra={
                "request_id": request_id,
                "method": request.method,
                "path": request.url.path,
                "client_ip": request.client.host,
                "user_agent": request.headers.get("user-agent"),
            }
        )
        
        response = await call_next(request)
        
        duration = time.time() - start_time
        
        # 记录响应日志
        logger.info(
            "request_completed",
            extra={
                "request_id": request_id,
                "status_code": response.status_code,
                "duration_ms": round(duration * 1000, 2),
            }
        )
        
        response.headers["X-Request-ID"] = request_id
        return response
```

```python
# exceptions.py — 企业级异常体系
from fastapi import HTTPException
from enum import Enum

class ErrorCode(Enum):
    # 系统错误 1xxxx
    INTERNAL_ERROR = (10001, "Internal Server Error", 500)
    SERVICE_UNAVAILABLE = (10002, "Service Unavailable", 503)
    TIMEOUT_ERROR = (10003, "Request Timeout", 504)
    
    # 认证错误 2xxxx
    UNAUTHORIZED = (20001, "Unauthorized", 401)
    FORBIDDEN = (20002, "Forbidden", 403)
    TOKEN_EXPIRED = (20003, "Token Expired", 401)
    
    # 业务错误 3xxxx
    INVALID_PARAMETER = (30001, "Invalid Parameter", 400)
    RESOURCE_NOT_FOUND = (30002, "Resource Not Found", 404)
    DUPLICATE_RESOURCE = (30003, "Duplicate Resource", 409)
    
    # RAG错误 4xxxx
    DOCUMENT_NOT_FOUND = (40001, "Document Not Found", 404)
    RETRIEVAL_EMPTY = (40002, "No Relevant Content Found", 404)
    LLM_GENERATION_FAILED = (40003, "Answer Generation Failed", 500)
    
    def __init__(self, code, message, status_code):
        self.code = code
        self.message = message
        self.status_code = status_code

class BusinessException(HTTPException):
    def __init__(self, error_code: ErrorCode, detail: str = None):
        self.error_code = error_code
        super().__init__(
            status_code=error_code.status_code,
            detail={
                "code": error_code.code,
                "message": error_code.message,
                "detail": detail or error_code.message,
            }
        )
```
